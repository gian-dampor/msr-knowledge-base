Data Sources

Data sources provide information that researchers can study to understand software development and software projects.

Data Source Types of Data Description
GitHub Source code, commits, issues, pull requests A platform for hosting code and collaborating on software projects.
Stack Overflow Questions, answers, comments, tags A question-and-answer website where developers discuss programming problems.
JIRA Bug reports, tasks, issues, project updates A project management tool used to track software development work.
App Stores App descriptions, ratings, reviews, version history Platforms such as Google Play and Apple's App Store that distribute applications.
Travis CI / Jenkins Build logs, test results, build status Continuous integration tools that automate software builds and tests.
Mailing Lists Messages, discussions, decisions, bug reports Archived email discussions that can show how developers communicate and make decisions.
npm Registry Package metadata, dependencies, versions A registry for JavaScript packages used to study software dependencies and package development.
