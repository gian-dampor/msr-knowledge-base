
# MSR Knowledge Base — Requirements

## 1. Project Overview

The MSR Knowledge Base is a website that helps new PhD students and researchers learn about Mining Software Repositories (MSR). It provides information about data sources, ways to collect and analyze data, and places to publish research.

## 2. Intended Users

- **New PhD students:** Students who are learning how to find and study software data.
- **MSR researchers:** Researchers who need information about data sources, research methods, and publication venues.

## 3. Functional Requirements

- **1 Navigation:** The website shall let users switch between four sections: Data Sources, Collection Methods, Analysis Methods, and Publication Venues.

- **2 Data Sources:** The website shall list GitHub, Stack Overflow, JIRA, App Stores, Travis CI/Jenkins, Mailing Lists, and the npm Registry. Each source shall include its name, the data it provides, and a short description.
  
- **3 Collection Methods:** The website shall list REST APIs, GraphQL, Web Scraping with Selenium, Web Scraping with BeautifulSoup, Database Dumps, and Manual Download. Each method shall explain what it does, its advantages, and its disadvantages.

- **4 Analysis Methods:** The website shall list Statistical Analysis, Regression Analysis, Thematic Analysis, Grounded Theory, Machine Learning, Time Series Analysis, Network Analysis, and Visualization. Each method shall explain what type of analysis it uses and what it is commonly used for.

- **5 Publication Venues:** The website shall list the conferences ICSE, FSE, ASE, MSR, EASE, and SANER, along with the journals EMSE, TSE, and TOSEM. Each venue shall include its name, abbreviation, type, main focus, and relevance to MSR research.

- **6 Content Organization:** The website shall display information using simple tables, lists, or cards.

- **7 Navigation Behavior:** When users select a tab or button, the website shall display the correct section.

## 4. User Stories

1. **Data Sources:** As a new PhD student, I want to see available data sources and the data they provide so that I can choose one for my research.

2. **Collection Methods:** As a researcher, I want to compare ways of collecting data so that I can choose the best method for my research.

3. **Analysis Methods:** As a researcher, I want to learn about different analysis methods so that I can choose one for my data.

4. **Publication Venues:** As a researcher, I want to compare conferences and journals so that I can find a suitable place to publish my research.

5. **Navigation:** As a website visitor, I want to switch between sections easily so that I can find information quickly.

6. **Readability:** As a researcher, I want information to be clearly organized so that I can understand and compare different options.

## 5. Non-Functional Requirements

- **Readability:** The information shall be easy to read and understand.
- **Simplicity:** The website shall be simple to use, without unnecessary animations or complicated features.
- **Appearance:** The website shall have a clean and professional design.

## 6. Project Scope

The project will be a simple website that provides useful information for MSR researchers. The first version will focus on one selected milestone. The remaining milestones will be described as future work, as required by the assignment.
